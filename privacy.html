Privacy Policy — Alex Drive Bridge

Last updated: 2026-09-12

1. Who this applies to

Alex Drive Bridge is a private, single-user tool operated by its owner on the owner's own computer. It has exactly one user: the person who installed it. No other person can create an account or authorise it.

2. What Google data the app accesses

The app requests one OAuth scope:
https://www.googleapis.com/auth/drive.file

Under this scope Google grants access only to:

  • files and folders that this app created, and
  • files the user explicitly selects and hands to the app through Google's file picker.

The app cannot access, read, list, modify, share or delete any other content in the user's Google Drive. It does not request or use the Google Drive full-access scope, and it does not access Gmail, Calendar, Contacts, Photos or any other Google service.

3. Why the data is accessed

Strictly for the app's single purpose: to create and update the user's own JSON workspace documents inside one folder the app created for that purpose. No data is used for advertising, profiling, analytics, or any purpose unrelated to that function.

4. How data is stored and shared

  • Documents are stored only in the user's own Google Drive, under the user's control.
  • The app has no back-end server and no database. Nothing is uploaded to the developer or to any third party.
  • No data is sold, rented, or disclosed to third parties.
  • No human other than the user reads the content the app writes.

5. Google API Services User Data Policy — Limited Use

Alex Drive Bridge's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Google user data is used only to provide the app's single, user-facing function.
  • Google user data is not transferred to third parties except as necessary to provide that function, to comply with applicable law, or as part of a merger/acquisition with prior user consent.
  • Google user data is not used for advertising, and is not sold.
  • No humans read the user's data, except (a) with the user's explicit consent, (b) for security purposes such as investigating abuse, (c) to comply with law, or (d) as part of internal operations where the data has been aggregated and anonymised.

6. Retention, revocation and deletion

The user may delete any document the app created at any time, directly in Google Drive. Revoking the app's access in the Google Account permissions page (myaccount.google.com/permissions) immediately and permanently ends the app's ability to access anything.

7. Security

OAuth credentials are stored locally on the user's own computer and are never transmitted anywhere except to Google's own OAuth token endpoint. The app is designed to fail closed: it refuses to act on any object outside the single folder it manages.

8. Changes

Any change to this policy will be published on this page with an updated date.
